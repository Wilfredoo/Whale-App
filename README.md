# Whale 🐋  
*A social geolocation app built with React Native & Firebase.*

Whale allows users to share their location with friends instantly, no matter where they are. Inspired by how whales use echolocation to find each other.

## 🚀 Tech Stack  
- **Frontend:** React Native, Expo  
- **Backend:** Firebase (Auth, Firestore, Hosting)  

## 🔧 Setup  
1. Clone the repository  
   ```bash
   git clone https://github.com/Wilfredoo/whale-app.git
   cd whale-app
   ```
2. Install dependencies  
   ```bash
   npm install
   ```
3. Start the app  
   ```bash
   expo start
   ```

## 🔥 Features  
- Real-time location sharing with friends  
- Secure authentication with Firebase Auth  
- Smooth mobile UI built with React Native  

📍 **Live Version (APK):** [Download on APKPure](https://apkpure.com/whale/com.wilfredo.geowhale)
